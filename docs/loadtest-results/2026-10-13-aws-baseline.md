## 용어

- **네트워크·k6**: k6 평균 - nginx rt 평균 (k6 요약이 있을 때만)
- **nginx 자체**: rt - vt - urt
- **verify 대기**: vt - verify 앱 시간
- **verify 앱**: auth-verify 안에서 쓴 시간
- **앱 앞 대기**: urt - 앱 시간 (네트워크·uvicorn·이벤트 루프 대기)
- **redis**: Redis 왕복 합계
- **db 풀·연결**: db - db_query (커넥션 대기·pre-ping·커밋)
- **db 쿼리**: SQL 실행
- **argon2 대기**: argon2 슬롯(세마포어) 대기
- **argon2 계산**: argon2 해시 계산(스레드풀 포함)
- **앱 나머지**: 앱 시간 - 위 구간들 (파이썬 CPU: 검증·직렬화 등)
- **층 순서 위반**: 안쪽 층 시간이 바깥 층보다 긴 요청 수. 0이 아니면 계측이나 로그 파싱을 의심합니다.
